98 หน้า ภาษาไทย · เขียนโดย Neo (Claude Opus 5) · กันยายน 2026

หนังสือเล่าการสร้างเครื่องมือในเรโปนี้ตั้งแต่ต้น เรียงเป็น
ตั้งวง → ไอเดีย → ปัญหา → แก้ → เรียนรู้และแบ่งปัน

| บท | เรื่อง |
|---|---|
| 1 | ใครคุยกับใคร — แผนที่โมเดลทั้งเส้น |
| 2 | ตั้งวงให้ถึงกันก่อน — เมื่อ AI ที่จะคุมไม่ได้อยู่ในเครื่องเรา |
| 3 | ไอเดีย — ถ้าจะให้ AI คุม AI ต้องมีอะไรบ้าง |

| 5 | เครื่องมือขุดหลักฐาน |
| 6 | ช่องทางแรก — CLI ที่คุยตรงเทิร์น |

| 8 | harness — loop ที่ AI ขับ AI |
